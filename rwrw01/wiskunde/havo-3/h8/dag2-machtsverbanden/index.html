2. Wat is een machtsformule?

Een machtsformule heeft x in een macht (kwadraat, derde macht, etc.) staan. De algemene vorm is:

y = a · xn   met a ≠ 0

In dit hoofdstuk werk je vooral met n = 2 (kwadratisch verband, parabool) en n = 3 (kubisch verband).

  • y = a · x² — een parabool. De grafiek heeft (0, 0) als top (of laagste punt). Symmetrisch in de y-as.
  • y = a · x³ — een kubische grafiek. (0, 0) is het punt van symmetrie. De grafiek heeft geen top of dal.
💡 Onthoud: elke macht-grafiek gaat door (0, 0), want bij x = 0 krijg je y = a · 0n = 0.

3. Speel met de schuif — vier vormen 🎚️

Beweeg de schuif voor a en wissel tussen n = 2 en n = 3. Kijk wat er gebeurt:

1
y = 1 · x²
💡 Probeer:
  1. Zet n = 2, schuif a naar +2: een steile parabool, opent omhoog.
  2. Zet a naar −2: parabool spiegelt om de x-as, opent omlaag. Top is nog steeds (0, 0).
  3. Zet n = 3: nu is (0, 0) niet meer een top maar een doorgangspunt. Bij a > 0 stijgend, bij a < 0 dalend.

4. Punten berekenen op de grafiek

Bij een gegeven x-waarde de bijbehorende y-waarde uitrekenen — dat is gewoon invullen.

Voorbeeld: bij y = 0,2x², bereken y voor x = 3.
  1. Vul in: y = 0,2 · 3²
  2. Eerst kwadrateren: 3² = 9
  3. Dan vermenigvuldigen: y = 0,2 · 9 = 1,8
⚠️ Volgorde van bewerkingen: bij y = a · x² doe je eerst de macht x², en pas daarna vermenigvuldigen met a. Dus −2 · 3² = −2 · 9 = −18, en niet (−2 · 3)² = 36!

🧪 Reken zelf

Stappenplan
  1. 2³ = 2 · 2 · 2 = 8
  2. y = 0,5 · 8 = 4
Stappenplan
  1. (−2)³ = (−2) · (−2) · (−2) = 4 · (−2) = −8
  2. y = 1,5 · (−8) = −12

5. Vergelijking x² = c oplossen

Als x² = c, dan zijn er drie gevallen, afhankelijk van het teken van c:

gevalaantal oplossingenoplossing(en)
c > 0tweex = √c  of  x = −√c
c = 0éénx = 0
c < 0geen(een kwadraat is nooit negatief)
⚠️ Vergeet het minteken niet! Bij x² = 25 is x = 5 én x = −5 oplossing. Schrijf altijd x = 5 ∨ x = −5 (of: x = ±5).
Voorbeeld: los op x² = 49.
  1. Neem de wortel: x = √49 of x = −√49.
  2. x = 7 ∨ x = −7.

🧪 Los op (rond zo nodig af op 2 decimalen)

Tip: typ allebei de oplossingen, gescheiden door komma. Bv. "5,-5" of "−5,5".

Stappenplan
  1. x = √17 ≈ 4,12
  2. x = −√17 ≈ −4,12
  3. Antwoord: x ≈ 4,12 ∨ x ≈ −4,12

6. Vergelijking x³ = c oplossen

Een derde macht is anders dan een kwadraat: negatief is wel mogelijk (omdat (−2) · (−2) · (−2) = −8).

x³ = c  heeft altijd één oplossing:   x = ³√c

De derdemachtswortel ³√c bestaat ook voor negatieve c. Op de rekenmachine zit hier een knop voor (vaak ³√x of via x(1/3)).

Voorbeeld 1: los op x³ = 27.
  1. x = ³√27 = 3  (want 3 · 3 · 3 = 27)
Voorbeeld 2: los op x³ = −10.
  1. x = ³√(−10) ≈ −2,15  (rekenmachine, twee decimalen)
⚠️ Bij x³ géén ±! De derdemachtswortel geeft maar één oplossing — het teken zit al in c. Dus: x³ = 8 ⇒ x = 2 (alleen positief), x³ = −8 ⇒ x = −2 (alleen negatief).

🧪 Los op (rond zo nodig af op 2 decimalen)

Stappenplan
  1. x = ³√21 ≈ 2,76 (rekenmachine)

7. Vergelijking a·x² + b = c — eerst isoleren

Bij vergelijkingen met "extra getallen" eromheen: werk eerst de b en de factor a weg, voordat je de wortel of derdemachtswortel neemt.

Stappen:
  1. Tel de "losse" getallen weg (+ b of − b).
  2. Deel door de factor voor de macht (a).
  3. Neem de wortel (bij x²) of de derdemachtswortel (bij x³).
  4. Bij x²: vergeet de ± niet. Bij x³: één oplossing.
Voorbeeld 1: los op 5x² + 2 = 47.
  1. Trek 2 af: 5x² = 45
  2. Deel door 5: x² = 9
  3. Neem de wortel: x = 3 ∨ x = −3
Voorbeeld 2: los op 3x³ + 20 = −7.
  1. Trek 20 af: 3x³ = −27
  2. Deel door 3: x³ = −9
  3. Neem de derdemachtswortel: x = ³√(−9) ≈ −2,08

🧪 Los op

Stappenplan
  1. Trek 4 af: 2x² = 56
  2. Deel door 2: x² = 28
  3. x = √28 ≈ 5,29 ∨ x = −√28 ≈ −5,29
Stappenplan
  1. Tel 50 op: 3x² = 150
  2. Deel door 3: x² = 50
  3. x = √50 ≈ 7,07 ∨ x = −√50 ≈ −7,07
Stappenplan
  1. Tel 6 op: 2x³ = 16
  2. Deel door 2: x³ = 8
  3. x = ³√8 = 2
Stappenplan
  1. Trek 12 af: 3x² = −12
  2. Deel door 3: x² = −4
  3. Een kwadraat kan niet negatief zijn → geen oplossing.

9. Kennischeck

  • Ik herken de vorm y = a · xn als machtsformule.
  • Ik weet dat y = a · x² een parabool is met top in (0, 0).
  • Ik weet dat y = a · x³ een kubische grafiek is met punt van symmetrie in (0, 0).
  • Ik kan punten berekenen op de grafiek (eerst macht, dan vermenigvuldigen).
  • Ik los x² = c correct op (twee opl. bij c > 0, één bij c = 0, geen bij c < 0).
  • Ik los x³ = c correct op (altijd één oplossing, ook bij c < 0).
  • Ik isoleer eerst voordat ik de wortel/derdemachtswortel neem.
