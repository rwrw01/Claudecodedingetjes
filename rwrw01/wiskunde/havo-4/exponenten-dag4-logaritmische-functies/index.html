2. Logaritmische vergelijkingen oplossen

Bij een logaritmische vergelijking gebruik je de definitie:

glog(x) = y   ⇔   x = gy

Je vertaalt dus van logaritme-vorm naar machts-vorm. Wat 'binnen' de logaritme staat (eventueel een uitdrukking met x), wordt gelijk aan g tot de macht van de rechterkant.

Voorbeeld 1: los op 2log(2x − 1) = 3
  1. Vertaal: 2x − 1 = 23 = 8
  2. 2x = 9 dus x = 4½
Voorbeeld 2: los op 1 + 2 · 3log(x) = 7
  1. Eerst isoleren: 2 · 3log(x) = 6 dus 3log(x) = 3
  2. Vertaal: x = 33 = 27
⚠️ Eerst isoleren! Net als bij exponentiële vergelijkingen: getallen of factoren die buiten de logaritme staan moet je eerst wegwerken voordat je de definitie toepast.

4. De standaardgrafiek y = glog(x)

De grafiek van y = glog(x) is het spiegelbeeld van de exponentiële grafiek y = gx in de lijn y = x. Daarom:

  • domein Df = (0, →)   (alleen positieve x mag!)
  • bereik Bf = ℝ
  • de y-as (lijn x = 0) is de verticale asymptoot
  • de grafiek gaat altijd door (1, 0), want glog(1) = 0

5. Transformaties op een logaritmische functie

Net als bij exponentiële functies kun je y = glog(x) verschuiven en rekken. De algemene vorm is:

f(x) = glog(ax + b) + c

De verticale asymptoot ligt bij de x-waarde waar het argument ax + b = 0:

verticale asymptoot: x = −b/a

Het domein hangt af van het teken van a: argument moet positief zijn. Bij a > 0 geldt x > −b/a.

💡 Truc: de verticale asymptoot ligt waar de waarde tussen de logaritme-haakjes 0 wordt. Stel dus ax + b = 0 en los x op.
Voorbeeld: bepaal de verticale asymptoot van f(x) = 3log(2x + 6) − 1.
  1. Stel het argument 0: 2x + 6 = 0
  2. x = −3
  3. Verticale asymptoot: x = −3. (De −1 buiten de log heeft hier geen invloed op.)

Opgave 81 — bereken voor welke x geldt f(x) ≤ 7

Gegeven: f(x) = 3log(2x − 5) + 4. Bepaal voor welke x geldt f(x) ≤ 7.

Stappenplan
  1. Eis dat het argument positief is: 2x − 5 > 0 dus x > 2,5.
  2. Los nu f(x) = 7 op: 3log(2x − 5) = 3 dus 2x − 5 = 27 dus x = 16.
  3. Omdat 3log stijgend is, geldt f(x) ≤ 7 voor 2,5 < x ≤ 16.
