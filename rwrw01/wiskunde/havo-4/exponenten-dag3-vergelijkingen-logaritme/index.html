2. Exponentiële vergelijkingen oplossen

Als links en rechts hetzelfde grondtal staat, mag je de exponenten aan elkaar gelijkstellen:

gA = gB  ⇔  A = B  (mits g > 0, g ≠ 1)

De truc is dus: zorg dat je aan beide kanten hetzelfde grondtal krijgt, daarna stel je de exponenten gelijk.

Voorbeeld 1: los op 5x − 2 = 25√5
  1. 25 = 52 en √5 = 5½, dus 25√5 = 52 · 5½ = 52½
  2. Vergelijking wordt: 5x − 2 = 52½
  3. Exponenten gelijk: x − 2 = 2½, dus x = 4½
Voorbeeld 2: los op 2 · 32x − 1 = 18
  1. Deel beide kanten door 2: 32x − 1 = 9
  2. 9 = 32, dus: 32x − 1 = 32
  3. 2x − 1 = 2, dus x = 1½
⚠️ Eerst isoleren: als er een factor of getal voor of na de macht staat (zoals "2 · 3x" of "3x + 5"), haal die er eerst af voordat je grondtallen gelijk maakt.

3. Oefenopgaven 62, 63, 64

Opgave 62 — bereken exact de oplossingen

a) 2x − 3 = ¼

Stappenplan
  1. ¼ = 1⁄22 = 2−2
  2. 2x − 3 = 2−2
  3. x − 3 = −2 dus x = 1

b) 5x − 20 = 105

Stappenplan — let op!
  1. Eerst isoleren: 5x = 125
  2. 125 = 53
  3. 5x = 53 dus x = 3

c) 5 · 2x = 80

Stappenplan
  1. Deel door 5: 2x = 16
  2. 16 = 24 dus x = 4

d) 32x + 7 = 27√3

Stappenplan
  1. 27 = 33 en √3 = 3½
  2. 27√3 = 33 · 3½ = 33½
  3. 2x + 7 = 3½ dus 2x = −3½ dus x = −1¾ = −1,75

Opgave 63 — exact oplossen

a) 3 · 2x + 4 = 28

Stappenplan
  1. Trek 4 af: 3 · 2x = 24
  2. Deel door 3: 2x = 8 = 23
  3. x = 3

b) 52x − 4 = 1⁄25

Stappenplan
  1. 1⁄25 = 5−2
  2. 52x − 4 = 5−2 dus 2x − 4 = −2
  3. x = 1

Opgave 64 — exact oplossen

a) 2x = ¼√2

Stappenplan
  1. ¼ = 2−2 en √2 = 2½
  2. ¼√2 = 2−2 · 2½ = 2−1½
  3. x = −1½

b) 22x + 1 = 8 · 2x

Stappenplan
  1. Schrijf rechts als één macht: 8 · 2x = 23 · 2x = 2x + 3
  2. 22x + 1 = 2x + 3 dus 2x + 1 = x + 3
  3. x = 2

4. Bruggetje — wat is de "omkering" van een macht?

Hieronder zie je een tabel met machten van 3:

x0123456
3x1392781243729

Vraag: bij welke x hoort de uitkomst 81?

Antwoord: x = 4, want 34 = 81.

3log(81) = 4   betekent: 'de exponent waarmee je 3 moet verheffen om 81 te krijgen, is 4'

Macht (bekend)

34 = 81
25 = 32
103 = 1000

Logaritme (nieuw)

3log(81) = 4
2log(32) = 5
10log(1000) = 3

5. De logaritme — definitie

glog(x) = a   ⇔   ga = x

glog(x) heet "de g-logaritme van x" en is de exponent waarmee je g moet verheffen om x te krijgen. Voorwaarden: g > 0, g ≠ 1, x > 0.

💡 Twee handige regels:
glog(ga) = a   (de logaritme 'pakt de exponent eruit')   bijvoorbeeld: 2log(25) = 5
gglog(x) = x   (logaritme en macht heffen elkaar op)   bijvoorbeeld: 33log(7) = 7
⚠️ Lees de notatie goed: in 2log(x) staat de 2 als klein superscript vóór "log" — dat is het grondtal. Het is dus iets anders dan log(x2) (waar 2 een macht van x is) en ook anders dan 2 · log(x) (vermenigvuldigen).
Voorbeeld: bereken 2log(8√2).
  1. 8 = 23 en √2 = 2½
  2. 8√2 = 23 · 2½ = 23½
  3. 2log(23½) = 3½
