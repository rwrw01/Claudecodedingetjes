1. Helling-functies met breuken en wortels — kan dat?

In §6.1 heb je geleerd hoe je f'(x) berekent voor functies als x², x³ en sommen daarvan.

De regel was:

f(x) = xn geeft f'(x) = n · xn−1

Maar wat doe je bij 1/x²? Of bij √x?

Het mooie: de regel werkt nog steeds. Je moet alleen eerst de functie herschrijven in de vorm xn.

Daarvoor heb je iets nodig wat je in H5 bij exponenten hebt gezien. Een korte opfris:

UIT H5 — EXPONENTEN

Een negatieve exponent betekent een breuk:

x−n = 1/xn

Een gebroken exponent betekent een wortel:

x1/n = n√x

Speciaal geval: x1/2 = √x.

Vul dit eerst zelf even in. Geen rekenmachine — denk terug aan H5.

Probeer zelf — herschrijven met exponenten

Stappenplan
  1. 1/x³ = x−3 (negatieve exponent = breuk)
  2. √x = x1/2 (gebroken exponent = wortel)
  3. 1/√x = 1/x1/2 = x−1/2 (combineer beide regels)

2. Theorie A — negatieve gehele exponenten

De machtsregel uit §6.1 werkt ook als n een negatief geheel getal is. Dus voor n = −1, −2, −3, …

REGEL Voor elk negatief geheel getal n geldt:
f(x) = xn geeft f'(x) = n · xn−1
VOORBEELD

Differentieer g(x) = 1/x².

Stap 1. Schrijf in de vorm xn:

g(x) = 1/x² = x−2

Stap 2. Pas de regel toe — exponent voor de x, en doe er 1 af:

g'(x) = −2 · x−2−1 = −2x−3

Stap 3. De functie zelf was met een breuk gegeven (1/x²), dus schrijf het antwoord ook met een breuk terug:

g'(x) = −2/x³
LET OP — afspraak Laat een negatieve exponent in je antwoord alleen staan als de functie zelf met negatieve exponenten gegeven was.
In alle andere gevallen: schrijf het terug als breuk.
VOORBEELD

Differentieer f(x) = 6/x³.

Stap 1. Herschrijf:

f(x) = 6/x³ = 6x−3

Stap 2. Pas de regel toe (constante blijft staan):

f'(x) = 6 · (−3) · x−4 = −18x−4

Stap 3. Terug naar breuk:

f'(x) = −18/x⁴

Probeer zelf — negatieve exponenten

Stappenplan
  1. f(x) = 5/x³ = 5x−3. f'(x) = 5 · (−3) · x−4 = −15x−4 = −15/x⁴
  2. g(x) = 3/x² = 3x−2. g'(x) = 3 · (−2) · x−3 = −6x−3 = −6/x³
  3. h(x) = (x²+1)/x³. Eerst splitsen: h(x) = x²/x³ + 1/x³ = x−1 + x−3
  4. h'(x) = −1·x−2 + (−3)·x−4 = −x−2 − 3x−4 = −1/x² − 3/x⁴

3. Theorie B — gebroken exponenten (wortels)

De regel werkt ook als n een gebroken getal is, zoals ½, ⅓, 3/2.

REGEL Voor elk getal n (geheel, breuk of negatief) geldt:
f(x) = xn geeft f'(x) = n · xn−1
VOORBEELD

Differentieer f(x) = √x.

Stap 1. Schrijf de wortel als exponent:

f(x) = √x = x1/2

Stap 2. Pas de regel toe — exponent voor de x, en doe er 1 af:

f'(x) = ½ · x1/2 − 1 = ½ · x−1/2

Stap 3. De functie was met een wortel gegeven, dus schrijf het antwoord ook met een wortel terug:

f'(x) = ½ · 1/x1/2 = 1/(2√x)

Controle op figuur 2: in x = 4 is f'(4) = 1/(2·2) = ¼. De raaklijn heeft helling ¼ — klopt met de figuur.

VOORBEELD

Differentieer g(x) = x · √x.

Stap 1. Combineer tot één macht van x:

g(x) = x · √x = x1 · x1/2 = x3/2

(Onthoud uit H5: bij vermenigvuldigen van zelfde grondtal tel je de exponenten op. 1 + ½ = 3/2.)

Stap 2. Pas de regel toe:

g'(x) = (3/2) · x1/2

Stap 3. Terug naar wortelvorm:

g'(x) = (3/2) · √x = 1½√x
LET OP — afspraak Laat een gebroken exponent in je antwoord alleen staan als de functie zelf met gebroken exponenten gegeven was.
In alle andere gevallen: schrijf het terug als wortel.

Probeer zelf — wortels differentiëren

Vul alle drie de antwoorden in als wortel of breuk (geen exponent), want de functies zijn met wortels gegeven.

Stappenplan
  1. f(x) = √x = x1/2. f'(x) = ½ · x−1/2 = 1/(2√x)
  2. g(x) = x² · √x = x² · x1/2 = x5/2. g'(x) = (5/2) · x3/2 = (5/2) · x · √x = 2½x√x
  3. h(x) = 1/√x = 1/x1/2 = x−1/2. h'(x) = −½ · x−3/2 = −1/(2 · x3/2) = −1/(2x√x)

4. Herleiden naar standaardvorm

Heel vaak krijg je een functie die er nog niet uitziet als xn. Bijvoorbeeld een breuk met meerdere termen in de teller, of een breuk met een wortel onderin.

Dan moet je eerst herleiden vóór je differentieert.

Werkschema: herleiden vóór differentiëren

  1. Schrijf elke term van de teller boven de noemer (splits de breuk).
  2. Schrijf elke term in de vorm c · xn.
  3. Differentieer term voor term met de machtsregel.
  4. Schrijf het antwoord terug in de oorspronkelijke vorm (breuk of wortel).
VOORBEELD

Differentieer f(x) = (4x + 1)/√x.

Stap 1. Splits de breuk:

f(x) = 4x/√x + 1/√x

Stap 2. Schrijf elke term met een exponent. Gebruik x/√x = x1/x1/2 = x1/2:

f(x) = 4 · x1/2 + x−1/2

Stap 3. Differentieer term voor term:

f'(x) = 4 · ½ · x−1/2 + (−½) · x−3/2
f'(x) = 2x−1/2 − ½ · x−3/2

Stap 4. Schrijf terug met wortels (functie was met wortel gegeven):

f'(x) = 2/√x − 1/(2x√x)
VOORBEELD

Bereken exact de extreme waarden van f(x) = (x²+16)/(4x).

Stap 1. Herleid:

f(x) = x²/(4x) + 16/(4x) = ¼x + 4/x = ¼x + 4x−1

Stap 2. Differentieer:

f'(x) = ¼ + 4 · (−1) · x−2 = ¼ − 4/x²

Stap 3. Los op f'(x) = 0:

¼ − 4/x² = 0
4/x² = ¼
x² = 16
x = −4 ∨ x = 4

Stap 4. Bereken de y-waarden:

f(−4) = (16+16)/(−16) = −2 → maximum op linker tak
f(4) = (16+16)/(16) = 2 → minimum op rechter tak

Antwoord: max f(−4) = −2 en min f(4) = 2.

(Maximum is hier kleiner dan minimum omdat de grafiek uit twee losse takken bestaat — zie figuur 3.)

Probeer zelf — herleiden en differentiëren

1. Differentieer f(x) = (2x² − 3)/x². Tip: splits de breuk.

Stappenplan
  1. f(x) = 2x²/x² − 3/x² = 2 − 3x−2
  2. De 2 is een getal, dus die afgeleide is 0.
  3. f'(x) = 0 − 3 · (−2) · x−3 = 6x−3 = 6/x³

2. Differentieer g(x) = √x / x². Tip: schrijf eerst alles als één macht van x.

Stappenplan
  1. g(x) = √x / x² = x1/2 / x2 = x1/2 − 2 = x−3/2
  2. g'(x) = (−3/2) · x−5/2
  3. x−5/2 = 1/x5/2 = 1/(x² · √x)
  4. g'(x) = −3/(2x²·√x)

5. Toetsstijl-oefeningen

Op de toets krijg je opgaven met meerdere deelvragen die op elkaar bouwen. Een opgave is pas af als alle deelvragen kloppen.

Opgave A — machtsregel met breuk (uit de V-test, C5)

Gegeven is de functie f(x) = 2/x⁴.

Stappenplan
  1. f(x) = 2/x⁴ = 2x−4
  2. f'(x) = 2 · (−4) · x−5 = −8x−5
  3. De functie was met een breuk gegeven, dus schrijf terug als breuk: f'(x) = −8/x⁵

Opgave B — raaklijn opstellen (uit het boek, Opg. 26)

Gegeven is de functie f(x) = (3x + 3)/x. Het punt A is het snijpunt van de grafiek van f met de x-as. De raaklijn k aan de grafiek van f in punt A snijdt de y-as in punt B.

Stappenplan
  1. a) Snijpunt x-as: y = 0 ⇒ (3x+3)/x = 0 ⇒ 3x+3 = 0 ⇒ x = −1. Dus A(−1, 0).
  2. b) Herleid f: f(x) = 3 + 3/x = 3 + 3x−1. f'(x) = −3x−2 = −3/x²
  3. c) f'(−1) = −3/(−1)² = −3/1 = −3
  4. d) k: y = −3x + b. Door A(−1, 0): 0 = −3 · (−1) + b = 3 + b, dus b = −3. k: y = −3x − 3.
  5. e) Snijpunt y-as: x = 0 ⇒ y = −3. Dus B(0, −3).

Opgave C — synthese (link met exponenten H5)

Gegeven is de functie f(x) = (x² + 1)/(x · √x).

Stappenplan
  1. a) Schrijf x · √x = x1 · x1/2 = x3/2. Dan: f(x) = (x²+1)/x3/2 = x²/x3/2 + 1/x3/2 = x1/2 + x−3/2
  2. b) f'(x) = ½ · x−1/2 + (−3/2) · x−5/2 = 1/(2√x) − 3/(2x²√x)
  3. c) f'(1) = ½ − 3/2 = −1
  4. (Zie figuur 5 voor controle: de raaklijn op x = 1 daalt — helling negatief.)
