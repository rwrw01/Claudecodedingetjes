1Raaklijn en raakpunten — §6.1

Gegeven is de functie f(x) = ⅓x³ + ½x² + 4x + 1.

a) De lijn k raakt f in A met xA = 2 en snijdt de y-as in B. Bereken exact de coördinaten van B.
b) In de punten C en D op de grafiek van f is de helling van de raaklijn gelijk aan 4. Bereken exact de coördinaten van C en D.
Uitwerking

a)

f(2) = ⅓·8 + ½·4 + 8 + 1 = 8/3 + 2 + 8 + 1 = 8/3 + 33/3 = 41/3
f'(x) = x² + x + 4
f'(2) = 4 + 2 + 4 = 10

Lijn k: y = 10x + b. Vul A(2, 41/3) in:

41/3 = 10 · 2 + b = 20 + b
b = 41/3 − 60/3 = −19/3

B(0, −19/3).

b) Los op f'(x) = 4:

x² + x + 4 = 4
x² + x = 0
x(x + 1) = 0 → x = 0 ∨ x = −1

f(0) = 0 + 0 + 0 + 1 = 1, dus C(0, 1).

f(−1) = ⅓·(−1) + ½·1 + 4·(−1) + 1 = −⅓ + ½ − 4 + 1 = −2/6 + 3/6 − 18/6 = −17/6, dus D(−1, −17/6).

C(0, 1) en D(−1, −17/6).

2Extreme waarden — §6.1

Bereken exact de extreme waarden van f(x) = x³ − 3x² + 2.

a) Geef de afgeleide.
b) Voor welke waarden van x is f'(x) = 0?
c) Bereken de extreme waarden. Geef bij elk aan of het een maximum of minimum is.
Uitwerking
f'(x) = 3x² − 6x = 3x(x − 2)

Stel f'(x) = 0:

3x(x − 2) = 0 → x = 0 ∨ x = 2

De grafiek is een derdegraads functie met positieve leidende coëfficiënt: hij stijgt voor x < 0, daalt tussen 0 en 2, en stijgt weer na 2. Dus x = 0 is een maximum, x = 2 is een minimum.

f(0) = 0 − 0 + 2 = 2
f(2) = 8 − 12 + 2 = −2

max f(0) = 2 en min f(2) = −2.

3Differentiëren met machtsregel — §6.2

Differentieer de volgende functies. Schrijf het antwoord netjes in breukvorm of wortelvorm (geen negatieve of gebroken exponenten).

a) f(x) = 3/x⁴
b) g(x) = (8x² − 2x)/√x
c) h(x) = (x + 2√x)²
Uitwerking

a) Schrijf f(x) = 3x−4.

f'(x) = 3 · (−4) · x−5 = −12x−5 = −12/x⁵

b) Herschrijf eerst:

g(x) = 8x²/√x − 2x/√x = 8x3/2 − 2x1/2
g'(x) = 8·(3/2)x1/2 − 2·(1/2)x−1/2
g'(x) = 12x1/2 − x−1/2 = 12√x − 1/√x

c) Werk de haakjes eerst uit:

h(x) = x² + 2·x·2√x + (2√x)² = x² + 4x√x + 4x
h(x) = x² + 4x3/2 + 4x
h'(x) = 2x + 4·(3/2)x1/2 + 4 = 2x + 6√x + 4

4Kettingregel — §6.3

Differentieer met de kettingregel. Vergeet de binnenste afgeleide (·a) niet.

a) f(x) = (6x − 1)⁵
b) g(x) = 5/(2x − 3)⁴
c) h(x) = √(3x − 4) + x²
Uitwerking

a) Macht naar voren, exponent één lager, binnenste afgeleide ·6:

f'(x) = 5·(6x − 1)⁴·6 = 30(6x − 1)⁴

b) Schrijf g(x) = 5·(2x − 3)−4:

g'(x) = 5 · (−4) · (2x − 3)−5 · 2 = −40(2x − 3)−5
g'(x) = −40/(2x − 3)⁵

c) Schrijf √(3x − 4) = (3x − 4)1/2:

h'(x) = ½·(3x − 4)−1/2·3 + 2x
h'(x) = 3/(2√(3x − 4)) + 2x

5Wortelfunctie — maximum en raaklijn — §6.3

Gegeven is de functie f(x) = √(3x + 15) − ½x.

a) Bereken exact het maximum van f.
b) De lijn k raakt f in A met xA = 7 en snijdt de x-as in B. Bereken exact de x-coördinaat van B.
Uitwerking

a) Schrijf f(x) = (3x + 15)1/2 − ½x.

f'(x) = ½·(3x + 15)−1/2·3 − ½ = 3/(2√(3x + 15)) − ½

Stel f'(x) = 0:

3/(2√(3x + 15)) = ½
2√(3x + 15) = 6 → √(3x + 15) = 3
3x + 15 = 9 → x = −2
f(−2) = √9 − (−1) = 3 + 1 = 4

max f(−2) = 4.

b)

f(7) = √(21 + 15) − 7/2 = √36 − 7/2 = 6 − 7/2 = 5/2
f'(7) = 3/(2·6) − ½ = ¼ − ½ = −¼

Lijn k: y = −¼x + b. Vul A(7, 5/2) in:

5/2 = −¼·7 + b → b = 5/2 + 7/4 = 10/4 + 7/4 = 17/4

k: y = −¼x + 17/4. Snijpunt met x-as: y = 0:

0 = −¼x + 17/4 → ¼x = 17/4 → x = 17

B(17, 0).

6Optimaliseren — oppervlakte driehoek — §6.4

Gegeven is de parabool y = 16 − x². Op de parabool ligt het punt P(p, yP) met 0 < p < 4. Op de x-as ligt het punt Q(p, 0). De driehoek heeft hoekpunten O(0, 0), P en Q.

a) Stel de formule op voor de oppervlakte A van ΔOPQ als functie van p.
b) Bereken algebraïsch de afgeleide A'(p) en de waarde van p waarvoor de oppervlakte maximaal is.
c) Bereken de maximale oppervlakte. Rond af op twee decimalen.
Uitwerking

a) Driehoek ΔOPQ: basis OQ = p (op x-as), hoogte = yP = 16 − p².

A(p) = ½ · p · (16 − p²) = 8p − ½p³

b)

A'(p) = 8 − (3/2)p² = 8 − 1½p²

Stel A'(p) = 0:

8 − (3/2)p² = 0 → p² = 16/3 → p = 4/√3 = (4√3)/3 ≈ 2,31

(Negatieve waarde valt af omdat 0 < p < 4.)

c) Bereken A bij p = 4/√3:

A = 8·(4/√3) − ½·(4/√3)³ = 32/√3 − ½·64/(3√3)
A = 32/√3 − 32/(3√3) = (96 − 32)/(3√3) = 64/(3√3) = 64√3/9
A ≈ 12,32
