1Transformaties & bereik

Geef voor elke functie aan hoe de grafiek ontstaat uit een standaardgrafiek. Geef ook het bereik en de formule van de horizontale asymptoot.

a) f(x) = 1 − 3 · 0,5x
b) g(x) = 4 · 32x − 7
Uitwerking

a) standaardgrafiek y = 0,5x → vermenigvuldigen t.o.v. x-as met factor −3 → translatie (0, 1). Asymptoot y = 1; bereik Bf = (←, 1).

b) standaardgrafiek y = 3x → vermenigvuldigen t.o.v. y-as met factor ½ (want 32x betekent x → 2x) → vermenigvuldigen t.o.v. x-as met factor 4 → translatie (0, −7). Asymptoot y = −7; bereik Bg = (−7, →).

2Schrijf in de vorm y = b · gx

a) y = 5 · 32x + 1
b) y = 22x + 4
c) y = 1⁄52x − 1
Uitwerking

a) 5 · 32x + 1 = 5 · 32x · 31 = 5 · 9x · 3 = 15 · 9x. b = 15, g = 9.

b) 22x + 4 = 22x · 24 = 4x · 16 = 16 · 4x. b = 16, g = 4.

c) 1⁄52x − 1 = 5−(2x − 1) = 51 − 2x = 51 · 5−2x = 5 · (5−2)x = 5 · (1⁄25)x. b = 5, g = 1⁄25.

3Bereken exact de oplossingen

a) 3x + 2 = 9√3
b) 5 · 21 − 3x = 20
c) 8 · 4x = 2x − 5
Uitwerking

a) 9√3 = 32 · 3½ = 32½. Dus x + 2 = 2½, x = ½.

b) Deel door 5: 21 − 3x = 4 = 22. Dus 1 − 3x = 2, x = −1⁄3.

c) Schrijf links als macht van 2: 8 · 4x = 23 · 22x = 22x + 3. Vergelijking: 22x + 3 = 2x − 5. Dus 2x + 3 = x − 5, x = −8.

4Functieanalyse — bereik & ongelijkheid

Gegeven is de functie f(x) = 2 · (1⁄3)x − 2 + 2.

a) Geef het bereik van f.
b) Bereken exact voor welke x geldt 4 ≤ f(x) ≤ 20.
Uitwerking

a) (1⁄3)x − 2 > 0 dus 2 · (1⁄3)x − 2 > 0 dus f(x) > 2. Asymptoot y = 2; bereik Bf = (2, →).

b) Los de twee grenzen op:

  1. f(x) = 4: 2 · (1⁄3)x − 2 = 2 dus (1⁄3)x − 2 = 1 = (1⁄3)0 dus x = 2.
  2. f(x) = 20: 2 · (1⁄3)x − 2 = 18 dus (1⁄3)x − 2 = 9 = (1⁄3)−2 dus x − 2 = −2, dus x = 0.
  3. f is dalend (grondtal 1⁄3 < 1), dus f tussen 4 en 20 betekent x tussen 0 en 2.

Antwoord: 0 ≤ x ≤ 2.

5Logaritmische vergelijkingen

a) Bereken exact 4log(32).
b) Los exact op: 2log(3x − 5) = 4.
c) Geef de verticale asymptoot van h(x) = 3log(2x + 8) + 1.
Uitwerking

a) 32 = 25 = (4½)5 = 42½. Dus 4log(32) = 2½.

b) 3x − 5 = 24 = 16 dus 3x = 21, x = 7.

c) Stel argument 0: 2x + 8 = 0 dus verticale asymptoot x = −4.
